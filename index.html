🚀 GitHub Pages 웹 배포 방법 (1분 완료)

  1. 상단 [GitHub 커밋용 코드 복사] 또는 [index.html 다운로드] 버튼을 누릅니다.
  2. GitHub에서 새 저장소(mingu-dashboard)를 생성한 뒤 uploading an existing file로 index.html을 올리고 Commit 합니다.
  3. 저장소 Settings → Pages에서 Branch를 main으로 선택하고 Save를 누르면 전용 웹 주소가 생성됩니다.
  4. 스마트폰 크롬에서 해당 주소를 열고 [홈 화면에 추가]를 누르면 앱처럼 바로 실행됩니다.
